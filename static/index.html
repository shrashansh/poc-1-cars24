What Cars24 knows before sending an inspector

Pick a sample car or add photos, then run the pre-inspection.

  1. Capture QA checks each photo on the server (blur, light, resolution)
  2. Identity, variant, odometer, damage and document agents run in parallel
  3. Cross-check reconciles their findings with the RC
  4. Pricing narrows a real price reference using what was verified
  5. Explainer writes the seller message and inspector checklist
